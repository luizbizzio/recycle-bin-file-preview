# Security Policy

Thank you for helping keep **Recycle Bin File Preview** safe.

This project is a Windhawk mod that runs inside Windows Explorer (`explorer.exe`). A security issue may affect Explorer or the handling of files in the Recycle Bin.

## Supported versions

| Version | Security updates |
| --- | --- |
| 1.0.x | Supported |
| Earlier test versions (0.x) | Not supported |

Please use the latest available release when possible.

## Reporting a vulnerability

**Do not post security details or proof-of-concept code in a public issue.**

1. Open the [repository security page](https://github.com/luizbizzio/recycle-bin-file-preview/security).
2. If **Report a vulnerability** is available, use it to send a private report.
3. If private reporting is not enabled, [open a general issue](https://github.com/luizbizzio/recycle-bin-file-preview/issues/new) asking for a private contact method. Do not include sensitive details in that issue.

Please include, when possible:

- A short description of the issue and its possible impact.
- Your Windows version and Windhawk version.
- The affected mod version.
- Clear steps to reproduce the issue with **test files only**.
- Logs or screenshots with personal information removed.

Do not send personal documents, private deleted files, passwords, or other sensitive data.

## What happens next

The maintainer will review the report and may ask for more information. If the problem is confirmed, a fix may be prepared and published with a security advisory when appropriate. No fixed response or release time is guaranteed.

Please give the maintainer a reasonable chance to investigate before sharing full technical details publicly.

## Non-security bugs

For normal bugs, preview errors, crashes without a known security impact, or feature requests, use [GitHub Issues](https://github.com/luizbizzio/recycle-bin-file-preview/issues).
