# Contributing to Recycle Bin File Preview

Compile [`recycle-bin-file-preview.wh.cpp`](recycle-bin-file-preview.wh.cpp) as a local mod in Windhawk. Read the [README](README.md) for the File Explorer workflow.

## Review a change

Use disposable files of known types. Check that selecting a deleted item shows the appropriate preview while the item stays in the Recycle Bin. Try switching selection quickly, an unsupported format, and files with duplicate or non-ASCII names. After turning off the mod, verify normal Explorer behavior and that the disposable items remain recoverable.

Include the Windows build, Windhawk version, file type, and Preview Pane state when reporting a regression.
